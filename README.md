# Расписание школы «Дмитровский»

Сайт: https://stresslov.github.io/raspisanie/

Просмотр расписания класса, учителя и кабинета. Поддерживаются день, неделя, поиск и сохранение выбора на устройстве.

Страница размещена на GitHub Pages. Для загрузки и общей публикации Excel/CSV и PDF подключён существующий сервер расписания через config.js. Данные хранятся в общем хранилище; пароль проверяется сервером и не включён в эти файлы. Просмотр не требует регистрации. Управление: сайт → «Управление» → пароль владельца → загрузка → проверка → публикация.

Для параллельных занятий в Excel указывайте разные значения в столбце «Подгруппа». Уроки одного учителя с одинаковым временем, предметом и кабинетом объединяются в одну карточку со списком классов.

ФИО и обозначения передаются как в школьном источнике; отсутствующие имена, отчества и кабинеты не выдумываются. Коды учителей и вакансии отмечены примечаниями.

JSZip используется для чтения XLSX; лицензия: JSZip-LICENSE.txt. Остальной интерфейс — обычные HTML/CSS/JavaScript без сборки.
