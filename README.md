# Расписание школы «Дмитровский»

Сайт: https://stresslov.github.io/raspisanie/

Просмотр расписания класса, учителя и кабинета. День показывает все позиции уроков, неделя — читаемую таблицу с внутренней горизонтальной прокруткой. Поиск встроен в список выбора; последний выбор запоминается автоматически. Подгруппы находятся внутри одного урока: в колонках на компьютере и друг под другом на телефоне. Полные сведения доступны по нажатию на урок.

Страница и данные размещены на GitHub Pages. Просмотр читает data/school.json с этого же сайта, без прежнего сервера. Управление и замены записываются в репозиторий через GitHub API: нужен fine-grained personal access token с доступом Contents: Read and write к Stresslov/raspisanie. Ключ используется только в памяти вкладки, не входит в исходники и не сохраняется в localStorage. Старый пароль не применяется. Изменения становятся видны посетителям после публикации GitHub Pages.

Файл «Актуальное» сохраняет основное расписание. Для отдельной версии загрузите таблицу в черновик и выберите «Сохранить и опубликовать отдельно» с новым названием. Выбор файла находится сверху. Документы и звонки доступны в разделе «Управление»; просмотр не требует пароля.

PDF из школьной рассылки теперь можно распознать на GitHub Pages: «Управление» → «Распознать расписание из PDF». Распознавание выполняется в браузере, без прежнего сайта и внешнего сервиса. Формат: текстовый PDF aSc, один класс на странице, дни в столбцах, уроки в строках; до 20 МБ / 120 страниц. Фото и сканы не распознаются. Можно исправлять предметы, ФИО, кабинеты, время, классы и подгруппы; подтверждённый результат сначала попадает в черновик. Для проверки используйте отдельный файл «Проверка PDF», чтобы сохранить «Актуальное». Модуль Mozilla PDF.js поставляется в папке vendor/pdfjs вместе с лицензиями; её нужно загрузить целиком вместе с index.html. Сторонние CDN не используются.

В «Заменах» после входа доступны проверка выбранного периода и выгрузка назначений в CSV/JSON. Прямая отправка в МЭШ пока не подключена: необходимы официальная спецификация и доступ школы. Выгрузка — внутренний список для проверки, не подтверждённый формат импорта МЭШ. Отдельные школьные логины с ролями администратора и ответственного работают в подготовленной серверной версии; статический GitHub Pages использует ключ GitHub и не ограничивает его права до отдельных функций интерфейса.

После входа в «Замены» откройте «Сотрудники для замен без основного расписания»: ФИО и предметы сохраняются общим списком для всех файлов. Эти сотрудники участвуют в подборе, их недоступность можно отметить на день или отдельные уроки. Удаление из подбора не снимает уже назначенные замены. Пустые ячейки серые; уроки различаются цветами корпусов 1–4, электронные Э 10 / Э 11 имеют отдельный оттенок. Легенда не добавляется.

Назначенные замены выделены жёлтым фоном и подписью «Замена»; на плашке кабинета сохраняется цвет корпуса. Подбор: сначала учитель другой подгруппы этого класса, затем классный руководитель (определяется по «Разговорам о важном» в исходном расписании класса), затем прежние приоритеты предмета и предыдущего корпуса. Занятость и отсутствие проверяются до ранжирования.

В мобильном нижнем меню есть кнопка «На экран». Если браузер поддерживает системный запрос установки, кнопка вызывает его; иначе показывает инструкцию. При запуске с главного экрана сохраняется выбранное при добавлении расписание. Для обновления установки загрузите также manifest.webmanifest и PNG-значки из assets/branding. Общий архив обновления включает все эти файлы и не включает data. Не заменяйте текущую папку data исходной копией: в ней хранятся расписание, сотрудники и замены.

Для параллельных занятий в Excel указывайте разные значения в столбце «Подгруппа». Уроки одного учителя с одинаковым временем, предметом и кабинетом объединяются со списком классов. Полная сетка содержит минимум 10 уроков; время пустых позиций берётся из таблицы, а при отсутствии — из школьного PDF.

ФИО и обозначения передаются как в школьном источнике; отсутствующие имена, отчества и кабинеты не выдумываются. Коды учителей и вакансии отмечены примечаниями.

JSZip используется для чтения XLSX; лицензия: JSZip-LICENSE.txt. Для PDF используется Mozilla PDF.js 6.4.299; лицензии: vendor/pdfjs/LICENSE, standard_fonts и wasm. Готовую версию достаточно загрузить в репозиторий, запускать npm на GitHub не нужно.
